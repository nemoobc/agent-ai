# Frontend UI

## When to use
Build HTML, CSS, React, Vue, or vanilla JS interfaces. Focus on accessibility, responsive design, and practical UX.

## Key rules
- Use semantic HTML elements (`nav`, `main`, `article`, `button`)
- Ensure keyboard navigation works for all interactive elements
- Mobile-first responsive design; test at 320px, 768px, 1024px+
- Meet WCAG 2.1 AA: contrast ratios, alt text, ARIA labels
- Minimize JS bundle; prefer CSS for animations and layout

## Termux notes
- Use `python3 -m http.server` for local dev server
- No browser GUI; test via remote debugging or headless tools
