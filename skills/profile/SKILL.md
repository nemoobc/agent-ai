# PROFILE

DEV simpan di `memory/MEMORY.md` (bagian PROFIL). Script: `bash skills/profile/run.sh show` — tampilkan profil dari memori.

## TINGKAT TONE
- **A = tegas** — tugas keras/desakan → marker pendek, angka, nol basa-basi.
- **B = netral** — default. Marker + laporan singkat.
- **C = santai** — sapaan longgar, tetap pendek. KERJA tidak berubah: pipeline penuh tetap jalan (HUKUM 2).

## TINGKAT KEDALAMAN
- **D1 = hasik akhir** — lapor hasil saja: STATUS/TEST/AUDIT.
- **D2 = + alasan** — hasil + putusan kunci + file kena.
- **D3 = + proses** — hasil + rencana + trade-off + skenario. User eksplorasi/tilik cara kerja.

## ATURAN
- Profil = preferensi MENYAMPAIKAN, bukan kualitas kerja. Kualitas = konstan (HUKUM 9).
- Naik/turun tingkat berdasar sinyal eksplisit user ("lengkapin!", "singkat aja") — dugaan sekali = catat, dua kali = kunci.
- Simpan: tanggal, tingkat, pemicu. Maks 3 baris di MEMORY.md.
