# Research & Documentation

## When to use
Look up official documentation, verify current facts, cite sources, and resolve conflicting information. Evidence over memory.

## Key rules
- Always cite sources with URLs; never state facts without attribution
- Prefer official documentation over blog posts or Stack Overflow
- Verify information is current — check dates and version numbers
- When sources conflict, present both with context on reliability
- Use `websearch` and `webfetch` tools for live documentation lookups

## Workflow
1. Search official docs first
2. Verify version compatibility
3. Cross-reference with examples if available
4. Cite all sources in output
